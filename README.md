# Слова — Telegram Mini App для английского

Личное приложение: без бэкенда, без аккаунтов, без аналитики и рекламы.
Vite + TypeScript + React, сборка в статику, деплой на GitHub Pages.
Прогресс живёт в `WebApp.CloudStorage`, в обычном браузере — в `localStorage`.

## Запуск локально

```bash
npm install
npm run dev
```

Открывается по адресу **http://localhost:5173/english-words/** — путь с именем
репозитория, потому что `base` в `vite.config.ts` тот же, что на GitHub Pages.

В браузере приложение работает целиком: `window.Telegram` нет, обёртка
(`src/telegram/webapp.ts`) молча уходит на `localStorage`, тактильный отклик
и нативная кнопка «назад» просто отключаются.

## Сборка

```bash
npm run build
```

Сначала `tsc --noEmit` (проверка типов), затем `vite build` → `dist/`.
Проверить собранное: `npm run preview` — отдаёт `dist` по адресу
**http://localhost:4173/english-words/**, то есть ровно по тому пути, по которому
приложение будет жить на GitHub Pages.

Проверить словарь:

```bash
npm run check:words
```

Считает слова по уровням и частям речи, ловит дубли id, отсутствие ударения в
МФА, примеры длиннее 12 слов и записи без сочетаемости. Гонять после каждой
новой порции слов.

Проверить движок:

```bash
npm run check:engine
```

Прогоняет подбор дистракторов по всем 440 словам, ложных друзей по 50 раз на
слово, интервалы Лейтнера, полный урок из 20 слов, пропорции подбора,
шардирование прогресса и серию дней.

Проверить хранение:

```bash
npm run check:storage
```

Сбои чтения и записи CloudStorage (на моке), слияние прогресса двух устройств,
очередь несохранённого и её восстановление после перезапуска, лимиты ключей и
значений, свои слова.

## Деплой на GitHub Pages

1. Создать репозиторий с именем **`english-words`** (если имя другое — поменять
   `base` в `vite.config.ts` на `'/<имя-репозитория>/'`).
2. Запушить в ветку `main`.
3. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` соберёт и выложит `dist` сам.

Адрес получится: `https://<логин>.github.io/english-words/`

## Настройка кнопки в BotFather

1. `/newbot` → имя и username, если бота ещё нет.
2. `/mybots` → выбрать бота → **Bot Settings → Menu Button → Configure menu button**.
3. Прислать адрес приложения: `https://<логин>.github.io/english-words/` —
   **обязательно со слэшем на конце**. Без него GitHub Pages отвечает
   редиректом 301. Домен при этом не меняется, но лишний редирект — это и
   лишняя задержка, и риск: с Bot API 10.2 методы Mini App работают только
   с исходного домена, так что приложение должно открываться ровно по
   адресу из бота.
4. Прислать подпись кнопки, например `Слова`.
5. Иконку бота: `/mybots` → **Edit Bot → Edit Botpic**, прислать
   `assets/bot-icon.png` — 512×512, знак МФА «шва» на акцентном фоне.
   Исходник рядом: `assets/bot-icon.svg`, нарисован фигурами, шрифт не нужен.
   Тот же знак стоит фавиконом вкладки.

После этого кнопка рядом с полем ввода открывает приложение внутри телеграма.
Отдельно ничего запускать не нужно — это статика, сервера нет.

6. Описание бота — его видно до первого сообщения, а на `/start` бот не
   отвечает (сервера нет):
   - `/setdescription` — например: «Тренажёр английских слов B1–B2.
     Нажмите кнопку «Слова» внизу, чтобы начать.»
   - `/setabouttext` — одна строка для профиля бота.

### Требования к клиенту

Нужна версия Mini Apps 6.9+ (облачное хранилище). На более старом клиенте
приложение показывает «Обновите Telegram» и не даёт начать урок — иначе
прогресс некуда было бы сохранить. Остальные возможности включаются по версии:
нижняя полоса в цвет фона — 7.10+, запрет сворачивания свайпом — 7.7+,
«На домашний экран» — 8.0+.

### Интеграция с телеграмом

При старте: `ready()`, `expand()`, `disableVerticalSwipes()` (иначе свайп по
списку ответов сворачивает окно), `setHeaderColor` и `setBackgroundColor` в
`#FAF9F5`. Тема **фиксированно светлая**, `themeParams` пользователя
игнорируются. Высота берётся из `viewportStableHeight` в CSS-переменную
`--app-height`, а не из `100vh`.

`MainButton` не используется — она оформлена телеграмом и ломает дизайн,
все кнопки свои. Кнопка «назад» — только нативная `BackButton`.
Из начатого урока «назад» и закрытие окна — только после подтверждения
(`showConfirm`, `enableClosingConfirmation`): ответы пишутся в конце урока.

### Хранилище

`CloudStorage`: до 1024 ключей, значение до 4096 символов.

| ключ                | что внутри                                                    |
| ------------------- | ------------------------------------------------------------- |
| `progress_<уровень>` | `diligent:4:0:1738;eventually:1:3:1740;…` — слово : box Лейтнера : ошибки : день последнего показа |
| `stats`             | счётчики и история последних 20 уроков                        |
| `settings`          | набор, уровень, размер урока                                  |
| `cw_<id>`           | своё слово целиком в JSON — по ключу на слово                 |

Один ключ на уровень нужен потому, что все слова разом в 4096 символов не влезают.
Запись — в конце урока, а не после каждого слова.

Пока прогресс не прочитан, урок начать нельзя: иначе запись пустого прогресса
затёрла бы облако. Сбой чтения — экран «Не удалось загрузить» с повтором.
Запись идёт через очередь (`lib/sync.ts`): несохранённое лежит копией в
`localStorage` устройства (`ew-sync:pending`) и досылается при повторе, при
возврате в приложение или при следующем запуске. Перед записью уровень
перечитывается и сливается с облаком по дню последнего показа — уроки с двух
устройств не затирают друг друга.

## Тактильный отклик

`notificationOccurred('success' | 'error')` — на ответе в уроке.
`selectionChanged()` — на чипах, сегментах, карточках набора, строках списка.
`impactOccurred('light')` — на кнопках, озвучке, «Показать ещё».
Вне телеграма всё это молча выключается.
