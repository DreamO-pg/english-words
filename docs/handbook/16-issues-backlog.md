**Не проводился.** В репозитории и в AUDIT.md нет разбора изменений Bot API 10.0–10.4. Единственное упоминание — ограничение 10.2 «методы Mini App работают только с исходного домена» (находка T-04), и его влияние на живом клиенте не проверено.

## Идеи

Идеи не из багов, а из устройства продукта. Не приоритизированы и не согласованы.

| Идея | Зачем | Что нужно |
|---|---|---|
| Режим «с русского на английский» | Активный словарь, а не только узнавание | Новый тип карточки в `lesson.ts`; дистракторы `en` той же части речи |
| Режим ввода слова | Правописание | Экран с полем ввода, нормализация ответа |
| Аудирование | Восприятие на слух | Скрывать `en` до ответа, только кнопка звука; работает лишь при `canSpeak` |
| Экран статистики | Данные уже собираются (H-03) | История 20 уроков, точность, лучшая серия |
| Дневная цель / лимит новых слов | Не перегружать повторами завтра | Настройка и учёт новых слов за день |
| Состояние «на сегодня всё» | Честно сказать, что повторять нечего, вместо добора отдыхающими | Условие в `pickLessonWords` и экран |
| Пометить «знаю, не показывать» | Не тратить время на известные слова | Флаг в записи прогресса |
| Уровни A2 и C1 | Шире аудитория | Новые порции словаря ([03](03-content.md#добавить-новую-порцию-или-уровень)) |
| Тёмная тема | T-01 | Палитра и подписка на `themeChanged` |
| Напоминания | Вернуть пользователя в серию | Нужен сервер: бот с `chat_id` пользователей, расписание, проверка `initData`; прогресс серверу не виден, текст без цифр или с данными, которые присылает Mini App |
| Экспорт / импорт прогресса | Бэкап и перенос на другого бота | Кнопка «Скачать» (JSON) и «Загрузить»; `WebApp.downloadFile` (Mini Apps 8.0+) |
| Сброс прогресса | H-06 | См. [14](14-runbooks.md#сбросить-прогресс-пользователя-по-его-просьбе) |
| Слова в контексте наборов на экране «Мои слова» | Сейчас там весь словарь | Фильтр по набору и уровню |
