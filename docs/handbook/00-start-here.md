# 00. Начни отсюда

> Справочник по проекту **ишкушмиш**. В интерфейсе и в README приложение называется **«Слова»**, репозиторий — `english-words`.
> Источник правды для каждого утверждения — код в этом репозитории на коммите, где лежит этот файл. Где проверить по коду не удалось, стоит пометка **«не проверено»** с причиной.

## Что это за проект

**ишкушмиш («Слова»)** — тренажёр английской лексики уровней B1–B2 для русскоязычного ученика. Работает как Telegram Mini App: пользователь открывает чат с ботом, нажимает кнопку меню «Слова» рядом с полем ввода, и внутри Telegram открывается одностраничное веб-приложение. В нём он выбирает набор слов (по уровню или тематический), уровень и размер урока (10/20/30 слов), проходит урок, а в конце видит итог и разбор ошибок. Есть список «Мои слова» с поиском и фильтрами. Туда можно добавлять собственные слова.

Урок устроен так: показывается английское слово с транскрипцией, ниже четыре варианта русского перевода, нужно выбрать верный. После ответа выезжает карточка слова: значения, часть речи, уровень, живой пример с переводом, сочетаемость, близкие слова, предупреждение о ложном друге. Слово озвучивается синтезом речи. Слово, в котором ошибся, возвращается через 2–3 карточки в том же уроке. В конце урока прогресс каждого слова обновляется по **системе Лейтнера**: пять «коробок» (box 1–5) с интервалами повторения 1, 3, 7, 16 и 35 дней. Следующие уроки собираются из слов, срок повторения которых наступил, и из новых слов.

Технически это **чистая статика без сервера**. Vite + React 18 + TypeScript собираются в `dist/` и выкладываются на GitHub Pages workflow-ом GitHub Actions. Кода бота нет, бот — это только запись в BotFather с Menu Button. Бэкенда, API, базы данных, напоминаний и задач по расписанию тоже нет. Весь словарь (440 слов) зашит в JS-бандл. Прогресс, статистика, настройки и свои слова каждого пользователя хранятся в **Telegram CloudStorage** — облачном key-value хранилище, которое Telegram даёт каждой паре «бот + пользователь» и синхронизирует между устройствами. В обычном браузере вместо него используется `localStorage`.

## Глоссарий

Термины даны так, как они называются в коде; в скобках — где определены.

| Термин | Значение |
|---|---|
| **Слово**, `Word` | Запись словаря: `id`, `en`, `ru[]` (1–3 значения), `ipa`, `pos`, `level`, `sets[]`, `exampleEn`, `exampleRu`, `collocations[]`, необязательные `synonyms[]`, `falseFriend`, `falseFriendRu` ([`src/data/words.ts`](../../src/data/words.ts)). Подробно — [03](03-content.md#формат-записи) |
| `id` слова | Английское слово в нижнем регистре, пробелы заменены дефисами: `figure-out`. Уникален в словаре. Ключ прогресса |
| **Своё слово** | Слово, добавленное пользователем через форму. В `sets` у него `custom`, `ipa` пустая, хранится в ключе `cw_<id>` ([`src/lib/customWords.ts`](../../src/lib/customWords.ts)) |
| **Уровень**, `Level` | CEFR: `A1`, `A2`, `B1`, `B2`, `C1`. Слова есть только у `B1` (200) и `B2` (240). На главной показываются только уровни, в которых есть слова |
| **Часть речи**, `Pos` | `noun` сущ., `verb` глаг., `adj` прил., `adv` нареч., `phrase` выражение, `phrasal` фраз. глагол (`POS_LABEL`) |
| **Набор**, `set`, `WordSet` | Подборка для урока: `level` «По уровню» (все слова уровня), `it-work` «Работа и IT», `meetings` «Встречи», `phrasal` «Фразовые» (`SETS`). Тематический набор тоже режется по выбранному уровню. Служебный набор `custom` помечает свои слова, в списке наборов на главной его нет |
| **Пул**, `pool` | Слова выбранного набора и уровня, из которых собирается урок (`poolFor` в [`src/lib/lesson.ts`](../../src/lib/lesson.ts)) |
| **Урок**, `LessonState` | Одна сессия на 10, 20 или 30 слов. Состоит из карточек (`cards`), очереди показов (`queue`), позиции, счётчика закрытых слов (`done`) и счётчика ошибок по словам (`wrong`) |
| **Карточка урока**, `LessonCard` | Слово плюс четыре перемешанных варианта перевода и индекс верного (`correctIndex`) |
| **Карточка слова**, `WordCard` | Компонент с полной информацией о слове. Показывается после ответа и в «Моих словах» ([`src/components/WordCard.tsx`](../../src/components/WordCard.tsx)) |
| **Вариант**, **дистрактор** | Неправильный вариант ответа. Берётся из `ru[0]` другого слова того же уровня и той же части речи (`buildCard`) |
| **Ложный друг** | Слово, похожее на русское, но с другим значением (`magazine` ≠ «магазин»). `falseFriend` — текст предупреждения на карточке, `falseFriendRu` — ложное значение, которое обязательно ставится одним из вариантов. В словаре 24 таких слова |
| **Box**, коробка Лейтнера | Уровень усвоения слова от 1 до 5 (`WordProgress.box`). Box определяет интервал до следующего показа |
| **Интервал**, `INTERVALS` | `[1, 3, 7, 16, 35]` дней для box 1…5 ([`src/lib/leitner.ts`](../../src/lib/leitner.ts)) |
| **День**, `day`, `lastDay` | Целое число дней от 2020-01-01 по **местной** полуночи (`dayOf`, `today`). Например, 2026-11-12 — это день 2507 |
| **Срок наступил**, `isDue` | `сегодня − lastDay ≥ INTERVALS[box − 1]` |
| **Просрочка**, `overdueBy` | `сегодня − lastDay − INTERVALS[box − 1]`. Чем больше, тем раньше слово попадёт в урок |
| **Новое слово** | Слово пула, по которому ещё нет записи прогресса |
| **Отдыхающее слово** | Есть запись, срок не наступил. Попадает в урок только для добора, box при верном ответе не растёт |
| **Повтор** (на главной — «на повторе») | Слово с наступившим сроком (`isDue`), любого box |
| **«Знаю»**, «выучено» | `box ≥ 5`. Это не окончательный статус: через 35 дней слово снова приходит на повтор, ошибка возвращает его в box 1 |
| **«Учу»** | Есть запись прогресса и `box < 5` (фильтр в «Моих словах») |
| **«Трудные»** | `errors ≥ 2` (фильтр в «Моих словах») |
| `errors` | Счётчик в записи прогресса. Растёт на 1 за **урок**, в котором в слове была хоть одна ошибка, а не за каждую ошибку. Подробно — [02](02-learning-logic.md#что-считается-ошибкой) |
| **Ошибки урока**, `lessonMistakes` | Слова, в которых в этом уроке была хотя бы одна ошибка. Из них строятся «Разбор ошибок» и «Повторить ошибки» |
| «С первого раза», `firstTry` | Слова урока без единой ошибки. Это число в кольце на экране итога |
| **Серия**, `streak` | Сколько дней подряд был хотя бы один урок (`recordLesson`, `currentStreak` в [`src/lib/stats.ts`](../../src/lib/stats.ts)) |
| **Статистика**, `Stats` | Ключ `stats`: число уроков, ответов, верных ответов, серия, лучшая серия, день последнего урока, история последних 20 уроков |
| **Настройки**, `Settings` | Ключ `settings`: набор, уровень, размер урока, флаг «плашку домашнего экрана закрыли» |
| **CloudStorage** | `Telegram.WebApp.CloudStorage`: до 1024 ключей на пользователя и бота, ключ 1–128 символов `[A-Za-z0-9_-]`, значение до 4096 символов |
| **Шард** | Продолжение ключа прогресса уровня при переполнении 4096 символов: `progress_b1`, `progress_b1_1`, `progress_b1_2`… |
| **Очередь**, `pending` | Изменения, ещё не записанные в облако. Лежат в памяти и копией в `localStorage` под ключом `ew-sync:pending` ([`src/lib/sync.ts`](../../src/lib/sync.ts)) |
| `flush` | Отправка очереди в облако. Вызовы выполняются строго по одному |
| **Слияние**, `mergeLevelProgress` | Объединение двух версий прогресса уровня: по каждому слову побеждает запись с бо́льшим `lastDay`, при равенстве — локальная |
| `StorageError` | Ошибка хранилища (сбой, таймаут 8 с, недопустимый ключ, слишком длинное значение). Отличает «сбой» от «пусто» |
| **Фолбэк** | Режим вне Telegram: `localStorage` с префиксом `ew:` вместо CloudStorage. Haptic, BackButton и диалоги работают через браузер или молча отключены |
| **SDK** | Скрипт `https://telegram.org/js/telegram-web-app.js`, объект `window.Telegram.WebApp` |
| **Версия клиента** | Версия Bot API Mini Apps, которую поддерживает клиент Telegram (`WebApp.version`). Минимум — `6.9` (`MIN_VERSION`) |
| **Плашка**, `Banner` | Полоса сверху экрана с текстом и одной кнопкой: сбой синхронизации или ошибка удаления слова |
| **Haptic** | Тактильный отклик `HapticFeedback`: `success`, `error`, `select`, `tap` (`haptic` в `webapp.ts`) |
| **Экран** | Одно из состояний `ScreenName` в [`src/App.tsx`](../../src/App.tsx): `home`, `lesson`, `result`, `words`, `addWord`. Отдельно от них — служебные `LoadScreen`, `UpdateScreen`, `ErrorBoundary` |
| **«Колода», «карточка» в смысле флеш-карт** | В коде таких сущностей нет. Ближе всего «набор» (колода) и «карточка урока» |

## Как пользоваться этой докой

- **Новичку** стоит прочитать 00 → 01 → 06, чтобы понять продукт, затем 02, чтобы понять логику.
- **Разработчику перед правкой** — 09 → 07 → 08 и раздел по теме правки. Затем 13 (как проверить и выкатить).
- **Если что-то сломалось**, сразу открывайте 14.
- Ссылки на код ведут на файлы относительно корня репозитория. Номера строк в доке не используются (они быстро устаревают), вместо них указаны функции и константы, их легко найти поиском.
- Правило актуальности: если в PR меняется поведение, логика, словарь, тексты, формат хранения или инфраструктура, в том же PR обновляется `docs/handbook/` (и страницы в Notion). Правило записано в `CLAUDE.md`.
