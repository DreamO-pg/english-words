# 05. Каталог текстов интерфейса

> В исходном плане здесь был «Каталог сообщений бота». Бот сообщений не отправляет ([04](04-bot-in-telegram.md)), поэтому раздел перечисляет **все тексты, которые видит пользователь Mini App**: экраны, кнопки, подсказки, ошибки, системные диалоги Telegram.
> Тексты приведены дословно из кода. Подстановки: `<уровень>`, `<слово>`, `<N>`, `<M>`, `<версия>`. Колонки «callback_data» и «обработчик» заменены на «действие» и «функция/компонент».

Тексты не вынесены в отдельный файл локализации, они зашиты прямо в JSX. Чтобы поменять текст, нужно править компонент из колонки «Где».

## Системные диалоги Telegram (`showConfirm`)

Показываются нативным окном Telegram с кнопками «OK» / «Отмена» (текст кнопок зависит от клиента). В браузере и на клиентах ниже 6.2 — `window.confirm`.

| Когда | Текст | OK | Отмена |
|---|---|---|---|
| «Назад» в уроке, где уже есть ответ | Выйти из урока? Ответы этого урока не сохранятся. | На главную, урок потерян | Остаться в уроке |
| «Удалить слово» | Удалить «`<слово>`»? Прогресс по слову тоже удалится. | Удаление `cw_<id>` и прогресса | Ничего |
| Закрытие или сворачивание окна, пока идёт урок с ответами | Текст Telegram (`enableClosingConfirmation`), приложение его не задаёт | Окно закрывается | Остаётся |

| `saveCustomWord` | `слово слишком длинное` (обычный `Error`) |
| `<title>` страницы | Слова |
