# CLAUDE.md

Проект «Слова» (ишкушмиш): Telegram Mini App для английских слов, статика на GitHub Pages, прогресс в Telegram CloudStorage. Сервера и кода бота нет.

Полная документация — `docs/handbook/` (начинать с `docs/handbook/00-start-here.md`). Её копия — страницы Notion «ишкушмиш» (каждый раздел — подстраница с тем же номером и названием).

## Правило: документация обновляется в том же PR

Если PR меняет что-то из списка ниже, в **том же PR** обновить соответствующие разделы `docs/handbook/` **и** те же страницы в Notion:

| Что меняется | Разделы |
|---|---|
| Поведение Mini App, экраны, переходы, кнопка «назад», озвучка, анимации | 01, 05, 06 (и скриншоты в `docs/handbook/img/`, если экран изменился внешне) |
| Бот в BotFather (кнопка меню, описание, команды), появление серверного кода | 04, 12, 09, 11 |
| Логика обучения: подбор слов, варианты, Лейтнер, интервалы, серия, статистика | 02 (и константы в 12) |
| Словарь: слова, переводы, наборы, уровни, правила `check:words` | 03 |
| Тексты интерфейса | 05 |
| Работа с Telegram WebApp API, хранение, синхронизация, сборка | 07 |
| Ключи и форматы CloudStorage / localStorage | 08, 10 |
| Зависимости и их версии, структура репозитория | 09 |
| GitHub Actions, Pages, домен, BotFather | 11, 12, 13 |
| Процесс разработки, проверки, деплой | 13 |
| Найденная или исправленная проблема | 16 (и 15 — хронология и журнал решений) |

Если поменялось то, на что ссылается глоссарий или таблица «где искать X», — обновить и `00-start-here.md`.

В описании PR указать, какие разделы обновлены, или явно написать «документация не затронута» с причиной.

## Проверки перед PR

```bash
npm run check && npm run build
```

`check:words` не завершается с ошибкой при проблемах словаря: читать его вывод (блок `ПРОБЛЕМЫ:`) глазами.
